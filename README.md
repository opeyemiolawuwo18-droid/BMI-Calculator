# BMI-Calculator
This algorithm is built for practice and it calculates Body Mass Index from weight and height inputs then gives the category (e.g Normal, underweight e.t.c).

## Demo
No live site to demonstrate yet

## Features
Weight  
Height  
BMI  
Category

## How to run
1. Enter your weight
2. Enter your height
4. Check your BMI and BMI category

## Example
Enter your weight (kg) 46.67  
Enter your height (m) 1.48  
Your weight is 46.67kg, with 1.48m height.  
Your BMI is 21.31  
While your BMI Category is Healthy Weight

## How it works
It take in weight and height as input and calculate the BMI using the formula BMI = weight/height².  
Then it classify the results into categories, normal, overweight, underweight or obese.

## Future improvements
The future goal is to add a machine learning layer that can predict the the health of the user  
(i.e diabetes or not) using open dataset while this remains a practical project and not a product  
or medical device. The later goal is to edge the whole pipeline into a low cost device as a physical  
prototype that can work without internet to demonstrate hardware skills too.
